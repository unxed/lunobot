# oddyness

- Код: https://github.com/unxed/oddyness
- Задачи: карточки P01–P25 плана `docs/implementation/plan.md` репозитория (технические критерии живут там, учёт их не
  копирует — `AGENTS.md` п. 8, `docs/implementation/workflow.md` «Работа бота и lunobot»); тикеты и PR этого же репозитория
- PR: туда же, ветка `lunobot/pr/<слаг>` -> PR -> мерж в `main`; одна карточка (или её подкарточка) — один PR, вместе с
  тестами и строкой `Статус` карточки в `plan.md` (commit/PR и команда проверки)
- Кто вливает: Луноботы, по § 7.3, когда обязательные проверки зелёные (поручение владельца unxed/lunobot#248: «Пусть
  понемножку пилится небольшими атомарными RUP патчами»)
- Зависимости: [goWidgets](../goWidgets/PROJECT.md) (интерфейс; общие контролы правятся в goWidgets отдельным изменением,
  частных копий в oddyness нет — `AGENTS.md` п. 7)
- Язык общения: русский (README, документация); по языку автора тикета
- Отладка GitHub CI: да (компилируемый Go-проект, локально ничего не собирать)
- Диагностический workflow: нет; до его появления — диагностика в CI PR или в unxed/sandbox
- Режим публикации: PR (нет `lunobot/staging` и `quick.yml`, § 2)
- Обязательные проверки PR: все job'ы workflow `ci` на голове PR (заводит P01: gofmt, `go vet`, `go test ./...`, сборка
  `CGO_ENABLED=0` для Linux/Windows/macOS). PR только с `*.md` (документация, план) — без CI, если workflow их
  пропускает
- Покрытие: Codecov не подключен; цель — 80 % (Go по умолчанию, § 7.4), на своих изменениях не ниже
- Релизы: нет (тегов, релизов и workflow релиза нет; первый релиз — preview P25, «Публикация релиза — отдельное
  поручение» в `plan.md`); схема при появлении: vX.Y.Z с `v0.1.0`
- Особенности:
  - `AGENTS.md` обязателен: одна карточка за итерацию, первая незавершённая с завершёнными зависимостями; fail fast;
    негативные проверки; неизвестную семантику 1С — явной ошибкой, совместимость по своим тестам не заявлять
  - Go, goWidgets, `CGO_ENABLED=0` — инвариант; новая зависимость — с проверкой лицензии и необходимости
  - Toolchain совместим с goWidgets (`go 1.26.0` в его `go.mod` на 21-10-2026)
  - В отчёте карточки — шаблон из `workflow.md` («Карточка: Pxx, исходный commit: …»), что не запускалось — отдельно
  - Сейчас в репозитории только документация (исследование и план); P01 создаёт Go module и CI
