# crescent

- Код: https://github.com/unxed/crescent
- Что это: менеджер фоновых задач для Codex — перезапускает цели, когда сбрасываются лимиты (`codex app-server` по JSON-RPC, нативное окно на goWidgets); первая версия сохранена в `archive/`
- Задачи: тикеты и PR этого же репозитория; пока в тикетах пусто, работа идёт по пункту 5а § 5 (механизм/код-долги, найденные ботами)
- PR: туда же, ветка -> PR -> мерж в `main`
- Язык общения: по языку автора тикета
- Режим публикации: PR
- Отладка GitHub CI: да
- Диагностические workflow: `ci.yml` (Linux с `go test -race`, Wine, Windows); отдельного `sandbox.yml` нет
- Обязательная проверка: все job'ы `ci.yml` на SHA PR (gofmt, `go vet` для linux и windows, `go test -race ./...`, репетиция демона, Xvfb-смоук)
- Запись в `INDEX.md` не заведена — согласуется с владельцем (§ 2); проект ведётся как репозиторий-зависимость владельца
- Особенности: каталог `archive/` — прежняя версия, на неё код новой версии не ссылается; `cmd/crescent` и `internal/*` — актуальный код

Этот паспорт — то место, где живут отличия проекта от остальных. Не хватает ответа
на вопрос, который встал в работе, — дополни паспорт вместе с правкой по задаче.
