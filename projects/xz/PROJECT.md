# xz

- Код: https://github.com/unxed/xz
- Задачи: свой issue-трекер владелец отключил (форк upstream `ulikunitz/xz`); задачи
  приходят из зависимых проектов — как часть работы над их тикетами (пример: правка
  здесь ради [tar#4](https://github.com/unxed/tar/issues/4)) — или прямой командой владельца.
- PR: туда же, ветка -> PR -> мерж в main; ветки `lunobot/...` без префикса `codex/`.
- Зависимости: нет, самостоятельная библиотека (fork upstream). Потребители (по факту
  импортов в других unxed-репозиториях): [tar](../tar/PROJECT.md) (`go.mod` пинит
  конкретный тег, на 27-09-2026 это `v0.1.47`), через tar — транзитивно f4 и zipper.
- Покрытие: не проверялось, уточнить прежде чем брать задачи по покрытию.
- Язык общения: английский (upstream-репозиторий на английском).
- Особенности:
  - Issues отключены в самом репозитории — `gh issue list/view` вернёт ошибку
    "has disabled issues"; это не повод считать проект без задач, просто источник
    задач — только зависимые репозитории или владелец.
  - XZ хранит поток как последовательность независимо сжимаемых блоков (Block Header
    перед каждым блоком, backward-linked индекс в футере) — в отличие от gzip, который
    обычно один непрерывный поток. Это даёт естественную основу для O(1) random-access,
    аналогично тому, что GZIDX даёт для `.tar.gz` в tar.
  - Random-access API уже реализовано на `main`: `Block` (blocks.go), `ParseBlocks`
    (парсит backward-linked индекс по `io.ReaderAt`, в один проход, через несколько
    конкатенированных streams), `ReaderConfig.NewBlockReader` (декодирует один блок
    независимо, дана позиция на `Block.Offset`), `ReaderConfig.NewParallelReader`
    (параллельная декомпрессия на этой же основе). Коммит `fd355af`, тесты в
    `blocks_test.go`. Уже используется в tar (`fs.go`, `TestTarFS_XZRandomAccess`).
    Прежде чем брать новую задачу «экспортировать границы блоков» — проверь `git log`
    и `blocks.go`/`parallel_reader.go`, не сделано ли уже.

Этот паспорт — то место, где живут отличия проекта от остальных. Не хватает ответа
на вопрос, который встал в работе, — дополни паспорт вместе с правкой по задаче.
