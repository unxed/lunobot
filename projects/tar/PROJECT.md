# tar

- Код: https://github.com/unxed/tar
- Задачи: покрытие (§7.4) и правки, которые требуются для [f4](../f4/PROJECT.md) —
  форк, от которого f4 зависит через go.mod
- PR: туда же, ветка -> PR -> мерж в main
- Зависимости: нет
- Покрытие: настроено и работает (28-09-2026, Лунобот-3). Codecov подключён
  через `.github/workflows/coverage.yml` (OIDC-аплоад, без CODECOV_TOKEN);
  публичный API `https://api.codecov.io/api/v2/gh/unxed/repos/tar/report/`
  отдаёт содержательные per-file данные без токена (на момент проверки —
  67.49% по репозиторию). ВАЖНО: в JSON-ответе `line_coverage` второе число —
  это *состояние* строки (0=hit, 1=miss, 2=partial), а НЕ счётчик попаданий —
  легко перепутать знак и посчитать покрытые строки непокрытыми. Файлы
  `arcidx/*.go` показывают 0% — это ожидаемо: сгенерированный flatbuffers-код,
  реально компилируется и тестируется только под тегом `tarindex_simple`
  (отдельный шаг в coverage.yml), в обычный coverage.out не попадает.
  Наименее покрытая не-generated логика на момент проверки — extractor.go и
  fs.go; для них заведены юнит-тесты на непокрытые чистые хелперы, PR
  [#15](https://github.com/unxed/tar/pull/15).
- Язык общения: английский (upstream-репозиторий на английском)
- Особенности: форк upstream ulikunitz/xz... нет, это отдельный форк ratarmount-style
  tar-индексации; правка API требует парной правки в f4 и/или zipper

Этот паспорт — то место, где живут отличия проекта от остальных. Не хватает ответа
на вопрос, который встал в работе, — дополни паспорт вместе с правкой по задаче.
