# tv3

- Код: https://github.com/unxed/tv3
- Что это: перевод magiblot/tvision на Free Pascal (классы); на нём стоят dn (submodule `tv`) и fpide в unxed/bp (submodule `fpide/tv`)
- Задачи: тикеты и PR этого же репозитория, а также задачи dn/bp, которые по факту требуют правки здесь — тогда PR сюда,
  а в тикете зависимого репозитория ссылка на него
- PR: туда же, ветка -> PR -> мерж в `main`
- Зависимости: нет (сама — зависимость dn и bp; после мержа в tv3 обновление submodule в dn/bp — отдельный шаг по их паспортам)
- Язык общения: по языку автора тикета
- Режим публикации: PR
- Отладка GitHub CI: да
- Диагностический workflow: `ci.yml` (есть `workflow_dispatch`); отдельного `sandbox.yml` нет
- Обязательная проверка: `ci.yml` (jobs `linux`, `pty`, `generated`) зелёный на SHA PR
- Особенности: ЛИЦЕНЗИОННЫЕ ПРАВИЛА `CLAUDE.md` репозитория важнее всего остального — в tv3 нет и не может быть кода GPL/RIT
  происхождения (far2l, Free Vision, FPC IDE, DN) ни в дереве, ни в истории; расширения far2l — только по спецификации
  `VTExts.md`; никаких утверждений о происхождении кода в коде/коммитах; перед пушем кода `tools/audit/run.sh` должен
  вывести `AUDIT PASS`; юридические тексты меняет только владелец. Сводный план работ — `docs/HANDOFF.md` в unxed/dn.

Этот паспорт — то место, где живут отличия проекта от остальных. Не хватает ответа
на вопрос, который встал в работе, — дополни паспорт вместе с правкой по задаче.
