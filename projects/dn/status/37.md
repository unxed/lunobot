# unxed/dn#37 — I3c: остальные панельные клавиши Far за FarUxMode

План (14-10-2026, Лунобот-1, воркер ae4c3234). Сверка таблицы тикета с DN (actions.dna, panelroot/panelwin): уже как в Far и без
правок работают Tab, Ctrl+U, Ctrl+R, Ctrl+L/Q/T, Ctrl+O, Ctrl+F1/F2, Ctrl+Left/Right, Ctrl+\, Ctrl+PgUp/PgDn, Ctrl+A,
Alt+Gray± (BIOS-коды), Gray*, Ctrl+Shift+Ins/Alt+Shift+Ins. Нет функции в DN (не делаем, правило I0 «новых функций нет»):
Ctrl+M (восстановить выделение), Ctrl+F11 (сортировка по владельцу — в DN только флаг). F-клавиши, Alt+F, истории — unxed/dn#38.

Части (каждая — PR с pty-проверкой в tools/dn-linux-farux.py):
1. Ctrl+Gray+/- — выделить/снять по расширению текущего (в DN — по типу); Ctrl+Gray* и Ctrl+Gray± в терминальной форме
   (символ с чистым Ctrl, VK numpad или 0); farux pty-тест впервые в CI (dn-linux.yml). Ветка lunobot/pr/37-1of5.
2. Ctrl+F3..F10 — режимы сортировки (имя, расширение, время записи, размер, без сортировки, создание, доступ, описания),
   повтор — обратный порядок (флаг Inverted DN), Ctrl+F12 — меню сортировки; перехват до строки статуса (apploop), только
   при фокусе панели.
3. Ctrl+H — показ скрытых файлов (вместо DirBranch DN), Ctrl+B — строка функциональных клавиш, если в DN есть переключатель.
4. Alt+Gray± в терминальной форме (конфликт с Alt+'-' «Look»: различать по VirtualKey) и Alt+буква быстрого поиска для букв,
   которые строка статуса забирает раньше панели (Alt+B/C/S/L/R/X — дыра I2b).
5. pty-проверка совпадающих клавиш (Tab, Ctrl+U/R/Q/T/\\, Ctrl+PgUp/PgDn) при включённом FarUxMode.
