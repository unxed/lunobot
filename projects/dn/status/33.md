# dn#33 — Ctrl-O: фиолетовый фон, путь, команды без панелей

12-10-2026 (Лунобот-1): воспроизведено: после Ctrl-O под панелями белым на пурпурном ($5F, не первый цвет палитры $71 — не TBackground; не экран команд — его нет до первой команды). Спросил, что именно при Enter без панелей. Ответ (6120426390).

14-10-2026 (Лунобот-1): PR unxed/dn#43 влит (`d46e00f`): эхо команды на экране пользователя показывает путь через `~` (ShortPath в `dn/compat/dnrunlinux.pas`). «Пробуйте!» по этой части — комментарий 6162405489. Экспорт `PS1` в `sh -c` из того же PR неинтерактивной оболочке ничего не даёт, фон не чинит; в интерактивной подоболочке (`bash` из командной строки) он задаёт статичное приглашение — проверить и, вероятно, убрать.

14-10-2026 (Лунобот-1): часть 2 — PR unxed/dn#46 (`45d9be7`): причина $5F найдена — экран tv/ обнулён (цвета по умолчанию) до первой отрисовки, `InitVideo` копирует его в `UserScreen` через `ReadScreenCells`, а `Byte(TColorAttr)` для не-BIOS цвета даёт $5F; теперь `ReadScreenCells` и `CellAttr` используют `ToBIOS` (по умолчанию 7 на 0). Там же убран экспорт `PS1` из #43. Влит (`a779bee`), «Пробуйте!» — комментарий 6162662751.

Замечание: «полный путь внизу» из тикета — скорее всего приглашение командной строки DN (`TCommandLine.Draw`, `dn/src/cmdline.pas`, `Dir` целиком, обрезка до 49), а не эхо команды, которое правил #43.

14-10-2026 (Лунобот-1): часть 3 — PR unxed/dn#49 (`6294fed`), ждёт CI: `ShortPath` из `dnrunlinux.pas` перенесён в `DnPath` как `ShortHomePath` (только хосты без дисков), `TCommandLine.GetDir` пропускает `Dir` через него — приглашение внизу показывает `~`. `DnPath` теперь использует модуль `Dos` (GetEnv) — смотреть сборку Windows/DOS. После мержа — «Пробуйте!» в тикет.
