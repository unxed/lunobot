# dn#40 — M3: возможности mc в бюджете размера

14-10-2026 (Лунобот-1): сверено с main b6bb88c, план в тикете https://github.com/unxed/dn/issues/40#issuecomment-6163265516. Кода ещё нет, ветки нет.

Уже есть в main:
- ассоциации: `dn.ext` (Enter), `dn.vwr`/`dnalt.vwr` (F3/Alt+F3), `dn.edt` (F4) — `ExecExtFile` в `dn/src/dnexec.pas`, вызов в `dn/src/dnutil.pas` (`ViewFile`, ~стр. 1594); имена файлов — `dn/src/cfgdir.pas`; архивы открываются в панели сами;
- `Ctrl+O` — пользовательский экран (`cmShowUserScreen`, `dnutil.pas`); `cmTerminal` — модемный терминал, не подоболочка;
- палитры: `dn/src/palettes.pas`, файлы `.pal`;
- нет: фонового копирования, постоянной подоболочки, группового переименования по шаблону.

Размер: мини-сборка linux64 = 1 892 592 байт (замер в PR unxed/dn#45), цель тикета 1.1M. Решение: новые возможности сначала в полной сборке, в мини — только если влезают (записано в тикете).

1. Образец `dn.ext`/`dn.vwr` для типичных типов Linux (pdf, картинки, медиа через `xdg-open`) — посмотреть формат в `ExecExtFile` и существующие образцы в репозитории (`git ls-files | grep -i '\.ext$\|\.vwr$'`); pty-тест Enter/F3 по ассоциации (по образцу `tools/dn-linux-*.py`); шаг CI, печатающий размер `out/dn` мини-сборки.
