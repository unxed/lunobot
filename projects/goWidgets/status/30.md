Новый виджет библиотеки — путь `ListBox` по слоям (ADR-0012; `core/driver.go` WidgetKind/PropKey/EventKind, `core/core.go` Node и разбор событий, `api.go` Add…, каждый backend, тест в `backends/*/…test`). ### Шаг 4 — таблица (L1) и список архива

4a. **core + headless + ADR-0020 «Table».** Контракт: `core.KindTable`; необязательный интерфейс окна `TableWindow` (по образцу `FolderDialogWindow`): `SetTableColumns(h Handle, cols []TableColumn)`, `SetTableRows(h Handle, rows [][]string)`, `SetSortIndicator(h Handle, col int, descending bool)` (col −1 — без стрелки); `TableColumn{Title string; Align Align}` (`AlignLeft`/`AlignRight`); новое `EventHeaderClicked` (Int — колонка); выбор и активация — существующие `EventSelected`/`EventItemActivated` (Int — строка). `Caps.GridView=true` ставит только драйвер, реализующий `TableWindow`. API: `Window.AddTable(cols []TableColumn) (*Table, error)`, `(*Table).SetRows([][]string)`, `Rows()`, `Select(i)`, `SelectedIndex()`, `SetSortIndicator(col, desc)`, события `Selected`, `Activated` (`*vreactive.Event[int]`), `HeaderClicked` (`*vreactive.Event[int]`). Сортировка — дело приложения, бэкенд только рисует стрелку. Запасной путь в `api.go`: драйвер без `TableWindow` → создаётся `KindListBox`, строка = ячейки через «  │  » (выравнивание по ширине колонки пробелами, правые колонки — справа), `HeaderClicked` не срабатывает, `SetSortIndicator` — пусто; `Table.Fallback() bool` говорит об этом приложению. headless реализует `TableWindow` (хранит колонки/строки, умеет синтетически кликнуть заголовок для тестов). Тесты: `api` — headless (колонки, строки, Select, Selected/Activated/HeaderClicked) и запасной путь на фиктивном драйвере без `TableWindow` (строки ListBox склеены, Fallback=true). Готово: тесты зелёные, ADR-0020 в `docs/adr/`, `Caps.GridView` описан.

4b. **GTK**: `GtkTreeView` + `GtkListStore` (все колонки `G_TYPE_STRING`) в `GtkScrolledWindow`; `GtkTreeViewColumn` с `clickable`, сигнал `clicked` → `EventHeaderClicked`; `sort-indicator`/`sort-order` для стрелки; `changed` у `GtkTreeSelection` → `EventSelected`; `row-activated` → `EventItemActivated`; xalign 1.0 у правых колонок. Измерение высоты — как у ListBox (до 8 строк). Тест `backends/gtk/tabletest` под Xvfb: строки показаны, клик по заголовку (xdotool или `gtk_tree_view_column_clicked`) даёт событие, Enter на строке — активацию; скриншот в артефакты `CI gui`. Готово: `linux` зелёный, скриншот в артефакте.

4c. **Win32**: `WC_LISTVIEW` со стилем `LVS_REPORT | LVS_SINGLESEL | LVS_SHOWSELALWAYS`, `LVM_INSERTCOLUMNW` (fmt `LVCFMT_RIGHT` для правых), строки — `LVM_INSERTITEMW`/`LVM_SETITEMTEXTW` (или виртуальный `LVS_OWNERDATA` + `LVN_GETDISPINFOW` — проще для больших архивов, выбрать его, если `WM_NOTIFY` уже разбирается); `LVN_COLUMNCLICK` → `EventHeaderClicked`, `LVN_ITEMCHANGED` (LVIS_SELECTED) → `EventSelected`, `NM_DBLCLK` и Enter (`LVN_KEYDOWN` VK_RETURN) → `EventItemActivated`; стрелка — `HDM_SETITEMW` с `HDF_SORTUP/HDF_SORTDOWN` у заголовка (`LVM_GETHEADER`). Тест в `backends/win32/win32test` под Wine (cc580 уже в CI): колонки и строки читаются назад `LVM_GETITEMTEXTW`, клик заголовка — `SendMessage(WM_NOTIFY)`-эмуляция. Готово: `windows` зелёный.

4d. **Qt 5/6**: `QTreeWidget` с `setRootIsDecorated(false)`, `setHeaderLabels`, `header()->setSectionsClickable(true)`, `sectionClicked(int)` → `EventHeaderClicked`, `setSortIndicator`, `itemSelectionChanged`/`itemActivated`. Тест `backends/qt/qttest` (как `list_linux_test.go`). Готово: `linux` (Qt-job) зелёный.

4e. **Cocoa**: `NSTableView` в `NSScrollView`, источник данных — класс через objc-рантайм (как у ListBox в `cocoa_darwin.go`), `tableView:didClickTableColumn:` → `EventHeaderClicked`, `setIndicatorImage:inTableColumn:` (`NSAscendingSortIndicator`/`NSDescendingSortIndicator`), `tableViewSelectionDidChange:`, `doubleAction` → активация. Тест `backends/cocoa/cocoatest`. Готово: `macos` зелёный, скриншот.

4f. **zipgui: список архива.** Новый пакет `showcase/zipgui/listing` (без UI): `type Row struct{Entry engine.Entry}`, `Sort(rows, col Column, desc bool)` — каталоги всегда сверху, внутри групп — по колонке (Name — без учёта регистра, Size/Packed — по числу, Modified — по времени), стабильно; `Cells(e engine.Entry) []string` — Name, Size (`humanSize`), Packed («—» при −1), Modified («2006-01-02 15:04»), CRC32 (8 hex или пусто). Окно: под кнопками таблица Name / Size / Packed / Modified / CRC32 (Size, Packed — вправо), открытие архива в горутине (`engine.List`), заполнение через `app.QueueUpdate`; пока только корень архива (имена без «/»); клик по заголовку — сортировка, повторный — обратный порядок, стрелка на колонке. Тесты: `listing` (сортировка всех колонок, каталоги сверху, «—» для −1) и `main_test` в headless (открыть zip из `packSample`-подобного хелпера, строк столько, сколько записей корня). Готово: скриншоты `CI gui` на всех бэкендах.
