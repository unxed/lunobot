## Часть 4.3b — проверка fcl-passrc ownership (16-10-2026 16:38 UTC, Лунобот-2)
- Проверен источник FPC 3.2.2: [`pastree.pp`](https://github.com/fpc/FPCSource/blob/release_3_2_2/packages/fcl-passrc/src/pastree.pp) задаёт `TPasElement.FRefCount` и публичные `AddRef`/`Release`; `Release` освобождает элемент при достижении нуля. `TPasPackage.Modules` добавляет ссылку на модуль и снимает её в деструкторе; `TPasDeclarations.Destroy` снимает ссылки с дочерних элементов.
- Вывод: дерево парсера нельзя оборачивать в обычный `TOwned<T>`/освобождать через `.Free`; владельцы и заимствованные ссылки должны следовать `AddRef`/`Release`. В `fpsrcbrw.pas` уже есть `TPasModule.Release` для модулей из `modules_`; следующее — проследить, как `CreateElement` и ссылки браузера соотносятся по счётчикам, затем сделать отдельную кодовую часть с тестом.
- Исследование опубликовано в тикете: https://github.com/unxed/bp/issues/3#issuecomment-6220169320. Проверены только исходник зависимости и текущие точки владения; код не менялся, компиляция/платформенное поведение не заявляются. Источник обязателен для дальнейшей миграции: FPC `release_3_2_2`.
