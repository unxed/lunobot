# xkb-go

- Код: https://github.com/unxed/xkb-go (форк godesktop/xkb-go, upstream module path
  `github.com/thegrumpylion/xkb-go` — см. [[f4-upstreaming]], одна из шести реальных
  чужих зависимостей с апстримом. Ветка `main` = наша разработка, PR'ы в апстрим уже
  открыты по другим темам (см. docs/UPSTREAM.md в unxed/f4).
- Задачи: тикеты этого репозитория, а также тикеты в unxed/vtui, которые по факту требуют
  правки здесь (например unxed/vtui#10) — тогда PR открывается в xkb-go, а в тикете vtui
  оставляется `Touch unxed/vtui#N`.
- PR: ветка → PR → мерж в main (как обычно).
- Зависимости: сейчас `go.mod` пустой (0 внешних зависимостей). unxed/vtui#10 добавит
  `github.com/jezek/xgb` (X11 wire-протокол) и, для фоллбека на стороне vtui, keytrans
  уже есть отдельной зависимостью f4/vtui.
- Покрытие: есть `coverage.yml`, отдельного build/test-матричного workflow нет — CI здесь
  заметно легче, чем у f4/vtui.
- Язык общения: английский (апстрим-стиль репозитория, как и остальные упоминания в
  docs/UPSTREAM.md unxed/f4).
- **Владелец прямо попросил** (unxed/vtui#10, комментарий 2026-09-27T16:20:56Z): «когда
  закончишь, обязательно отправь эти наработки в upstream» — т.е. по завершении работы
  здесь нужен PR в godesktop/xkb-go по тому же образцу, что уже отправлены прошлые
  доработки этого форка (см. [[f4-upstreaming]]).
