# f4 #1622 — «2 issues in Color scheme» на старте

Суть: при каждом запуске f4 v0.3.0-beta тост «Color scheme: 2 issues found,
see debug.log for details», в debug.log две строки:

```
COLORS: [Menu.Highlight.Selected] harsh color clash: #cb0000 next to #4e9a06 ...
COLORS: [HMenu.Highlight.Selected] harsh color clash: #cb0000 next to #4e9a06 ...
```

Причина обеих строк одна: в стиле Default Dark слоты `Menu.Highlight.Selected`
и `HMenu.Highlight.Selected` (буква-акселератор пункта меню, когда сам пункт
выделен) сохраняли тот же красный foreground `#cc0000`, что и невыделенное
состояние `Menu.Highlight`/`HMenu.Highlight`, при этом background у выделенного
состояния — насыщенный зелёный `#4e9a06`. Красный на зелёном ловится
chroma/hue-clash валидатором vtui (f4#363, оба цвета высокой чистоты, ~88°
разница по тону) — в отличие от всех остальных `*.Highlight.Selected` слотов
этого стиля (например `Dialog.Button.Highlight.Selected`), которые на том же
зелёном уже используют светлый foreground.

Статус: фикс уже был закоммичен в `lunobot/staging` (коммит `a73f9a51`,
"theme: fix red-on-green hotkey clash in Default Dark menu selection",
трейлер `Touch: #1622`) до захвата этой сессией — видимо, предыдущим кругом
того же узла. Коммит меняет оба значения `foreground` на `#eeeeec` (тот же,
что уже использует `Dialog.Button.Highlight.Selected` на идентичном зелёном
фоне) и убирает Default Dark из `styleKnownColorIssues` в
`color_validate_test.go` (там эта пара была задокументирована как принятое
исключение — теперь не нужна). Прочитал диф — правка точечная и корректная,
разбирается с обоими классом ошибок одним изменением. Новых кодовых правок в
этом шаге не делалось, коммитить нечего.

Дальше: когда поезд `train.py tick` довезёт `a73f9a51` до `main`, тикету
нужно отправить «Пробуйте!» с текстом из секции `Проверить:` этого коммита
(сделает `tick`, увидевший зелёный поезд, по § 7.3/§ 7.2 п. 4). Падение
"FATAL PANIC IN RUN LOOP: assignment to entry in nil map" в конце приложенного

отключения wayland-композитора), в теле тикета не упомянут и не является
одной из заявленных «2 issues»; не трогал.
