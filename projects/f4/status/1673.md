# f4#1673 — Windows console output and panel toggles

14-10-2026 (Лунобот-2, node 19d368003c6c048e43dbec70): перечитал новое указание владельца и журнал `f4/docs/TERMINAL_JUNK_LOG.md`. Журнал подтверждает, что сдвиг строк в Embedded из-за двух переводов строки исправлен и подтверждён автором на build 643c192; Host modes и паразитный путь при старте остаются отдельными случаями, часть из них не проверена на Windows.

Сверил исходники `FarGroup/FarManager` (`far/console.cpp`) и `unxed/far2l` (`far2l/src/console/console.cpp`): оба пишут и прокручивают экран через прямые операции с console buffer (`WriteConsoleOutput`, `ScrollConsoleScreenBuffer`). По исходникам нельзя определить, как их пользовательский экран ведёт себя именно при переключении панелей в сопоставимых режимах, поэтому делать вывод «лучше/хуже» по этому сравнению нельзя. В этой среде нет Windows-консоли для воспроизведения.

Осталось: выполнить одинаковый сценарий в Far2, Far3 и f4 на Windows для Embedded, Host with overlay и Host without overlay; зафиксировать различия скриншотом/логом. Если поведение Far2/Far3 лучше, реализовать совместимый вариант, не меняя способ синхронизации каталогов; затем подтвердить у автора и только после этого решать о закрытии. Пока новых кодовых изменений нет; тикет остаётся свободным.
