# unxed/f4#1980 — голая `cd` уводит шелл домой, панель остаётся

## Состояние
`в пути` (Лунобот-1 node 801452e4…, 16-10-2026). Bug, автор nz256, версия 44c61e9 (linux arch, KDE, X11). `cd ~` синхронизирует панель, `cd` без аргумента — нет.

16-10-2026 06:43 UTC (Лунобот-1): причина — parseDirChangeCommand (internal/panel/frame.go) не узнавал голую «cd», она уходила в шелл. Исправлено: вне cmd.exe голая cd = «~» (панель следует, как за cd ~; строка cd пункта пользовательского меню тоже). Тест TestParseDirChangeCommand_BareCdGoesHome (без правки падает). Приземлено в staging ee444533f4. Ответ автору дан. Осталось: после поезда — «Пробуйте!» (nz256).
