**Результаты измерений:**
- Создан тестовый solid 7z архив: 100 файлов × 5 MB = 500 MB исходных данных
- Сжатие LZMA2: сжалось до 1% (5 MB архив) — данные высоко сжимаемые (повторяющиеся паттерны)
- Zipper full extraction: 1.18s (422 MB/s)
- Native 7z full extraction: 1.29s (387 MB/s)
- Zipper быстрее native 7z на полной распаковке (0.92x)

**Корень проблемы (из кода f4/plugins/archive/vfs.go):**
- При открытии файла из 7z-архива (строка 1374) принудительно используется `materialize()` — полная экстракция во временный файл
- `extractToTempSequential` (строка 1102) использует bulk extractor, который итерирует ВСЕ файлы архива до целевого
- Для solid-архива это означает декомпрессию всех предшествующих данных даже для пропускаемых файлов
- Библиотека `unxed/sevenzip` поддерживает random access через пул папок (`pool.Pooler`), кэшируя ридеры на разных оффсетах
- Но `archives.SevenZip.Extract` (mholt/archives) не предоставляет API для извлечения одного файла — всегда итерирует всё
