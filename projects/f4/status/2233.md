# unxed/f4#2233 — широкие таблицы в просмотре Markdown

Причина: раскладка таблицы живёт в vtui (`markdown.go`, `table()`), ширины окна она не знает, а `HelpView` режет слишком длинные строки таблицы по краю окна как обычный текст. Решение: таблица хранится в `HelpTopic.tables`, `wrapHelpTopic` при ширине окна меньше естественной перераскладывает её: самые широкие столбцы сужаются, текст длинных ячеек переносится внутри столбца (unxed/vtui, `markdown_table.go`). Чередование цвета фона строк (идея автора) — отдельной частью, если понадобится.
