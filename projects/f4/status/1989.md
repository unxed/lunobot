## Причина
`internal/panel/frame.go` (~3780, «Selection by mask (+, -, *) typed as plain characters on an empty command line»): при пустой командной строке символы `+`/`-`/`*` (e.Char) запускают Panel.SelectGroup/DeselectGroup/InvertSelection — запасной путь для терминалов, где серая клавиша приходит символом. На точном вводе (X11/TTYX, kitty, win32-input, GUI) основная клавиатура даёт тот же символ, и путь срабатывает ошибочно. Серые клавиши и так привязаны к действиям как Add/Subtract/Multiply (actions_table.go).

## План (одна часть, land)
1. Пометить событие, у которого код клавиши восстановлен из символа (`internal/keymap/farkeys.go` ~360: char → VK_OEM_MINUS/VK_OEM_PLUS), либо ввести признак «источник ввода сообщает физические клавиши» (TTYX активен, kitty/win32-input включены, GUI-бэкенд).
2. В frame.go запасной путь по символу — только для событий без точной клавиши; при точной — `+`/`-`/`*` основной клавиатуры идут в командную строку.
3. Тесты: событие с точной клавишей VK_OEM_MINUS + Char '-' при пустой строке — символ в строке, действие не вызвано; VK_SUBTRACT — DeselectGroup; событие из запасного (символьного) пути — прежнее поведение.
4. «Проверить:»: в панелях с пустой командной строкой набрать «-x» — строка «-x», окна снятия выделения нет; серый «-» — окно «Снять выделение».
