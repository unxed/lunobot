# unxed/f4#2068 — Cab-файлы не открываются как архивы

18-10-2026 10:09 UTC (Лунобот-1, node 19d368003c6c048e43dbec70; LNX): исследование. Плагин архивов (`plugins/archive/archive.go`) работает через `github.com/unxed/archives` (форк mholt/archives: `archives.Identify` + `Extractor`); формата CAB там нет. Готовых Go-библиотек (все MIT/Apache-2.0, все молодые):
- `github.com/abemedia/go-cabinet` (MIT, Go 1.25, клаус-компресс): `NewReader(io.ReaderAt)`, `fs.FS`, none+MSZIP, LZX/Quantum нет, но есть `RegisterDecompressor`; один файл (без цепочки кабинетов). Основной кандидат.
- `github.com/NextronSystems/lzx` (MIT): декодер LZX на Go — подключить через `RegisterDecompressor` для LZX.
- `github.com/NextronSystems/go-cab`, `github.com/google/go-cabfile` (Apache-2.0, минимум) — запасные.
Политика проекта — зависимости ведутся через форки `unxed/*` (`unxed/archives`, `unxed/zip` …), поэтому формат CAB добавляется в `unxed/archives` (файл `cab.go`, `Match` по сигнатуре `MSCF`, `Extract`, `Archive/FS`), а f4 поднимает версию `unxed/archives`.

Части (одна часть за круг, RUP):
1. `unxed/archives`: `cab.go` — Identify по `MSCF` в начале файла + чтение none/MSZIP через go-cabinet (скопировать нужное или require), тесты на готовом `testdata/*.cab` (создать кабинет `gcab`/`lcab` в CI-песочнице или writer go-cabinet в тесте). Критерий: тест Identify+Extract зелёный.
2. LZX: `RegisterDecompressor` с `NextronSystems/lzx`, тест на LZX-кабинете (фикстура — из testdata самого lzx/go-cab, лицензия MIT).
3. f4: bump `unxed/archives`, регистрация расширения `.cab` в плагине (`archive.go`, список форматов/ассоциации), тест `plugins/archive` на вход в .cab и F5; полный `go vet ./... && go test ./...` в песочнице (правка go.mod → `Sandbox-Full:`, § 7.2 п. 0).
4. Кабинеты в нескольких файлах (`CFHEADER.flags` next/prev) — по запросу.
