## Часть 1 — вопрос перед записью файла без права записи (Лунобот-1 node 801452e4…, 16-10-2026 07:17 UTC)
Причина: `EditorView.saveToFile` пишет временный файл и переименовывает его поверх, права исходного файла этому не мешают и потом восстанавливаются. Исправление: `SaveToFile` спрашивает Editor.ReadOnlySave* (en/ru) для локального файла без w-битов (Windows — атрибут read-only); Отмена — не сохраняет, Сохранить — пишет, права сохраняются, повторно не спрашивает (`readOnlyConsent`). Тесты `internal/editor/readonly_save_test.go` (мутант ловится; на Windows проверяется только вопрос). Приземлено в staging 24536a0d7b. После поезда — «Пробуйте!» (текст в «Проверить:» коммита).

## Часть 2 — Ctrl+A: снятие последнего атрибута «R» не срабатывает (сделана)
Автор: «если по Ctrl+a убрать последний атрибут 'R' то на самом деле он не убирается». Начать с диалога атрибутов (Attributes.ReadOnly в lng, код диалога — grep «Attributes.ReadOnly» в internal/), воспроизвести на файле 0400: снять R, применить, проверить режим файла. Вероятно, снятие R без других изменений не меняет режим (сравнение «ничего не изменилось» или маска только на добавление).
