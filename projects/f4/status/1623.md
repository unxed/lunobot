# f4#1623 — проверка контрольных сумм (аналог IntChecker)

Спецификация автора (tarlabnor, комментарий 2026-09-28): команда → меню
«Generate hashes» / «Validate files»; в Generate — алгоритм (радиокнопки),
вывод (Single file / Separate hash files / Directory hash files / Display),
опции (рекурсия, абсолютные пути, фильтр по маске), кодировка файла;
Validate — по файлу сумм под курсором или с запросом пути, запрос каталога
при ненайденных файлах. Прогресс (текущий + общий) и отмена обязательны.
Образец — https://github.com/lazyhamster/IntChecker

## Части

1. ГОТОВО (Лунобот-3, 28-09-2026, `e055f3d9` в `lunobot/staging`):
   плагин `plugins/intchecker`, меню с «Вычислить хэши...», диалог
   (6 алгоритмов, вывод «один файл» с редактируемым именем), хэширование
   отмеченных файлов текущего каталога с прогрессом и отменой, формат
   coreutils `<hex> *<name>` / SFV, запись только после полного чтения.
2. ГОТОВО (Лунобот-3, 28-09-2026, `e172269d` в `lunobot/staging`):
   «Проверить файлы...» в меню; файл сумм под курсором или диалог
   (файл сумм + каталог, пусто = текущий); разбор coreutils/SFV/GNU-escape,
   алгоритм по расширению, иначе по длине; если ни один файл не найден —
   диалог возвращается с просьбой указать каталог; прогресс и отмена как в
   части 1; итог — счётчики OK/несовпадение/не найден/ошибка чтения и до 10
   проблемных файлов.
3. ГОТОВО (Лунобот-3, 28-09-2026, `9a4f300c` в `lunobot/staging`):
   выбор «Вывод» (один файл / отдельный на каждый файл / на каждый каталог
   `<имя каталога><ext>` / окно с «Копировать в буфер» и «Сохранить в
   файл...»); существующие файлы сумм — вопрос до подсчёта: перезаписать /
   пропустить существующие / отмена; ошибка записи одного файла не
   останавливает остальные; группировка по каталогам уже готова к рекурсии
   (`outputFor`: `sub/x` → `sub/sub.md5`). Комментарий:
   https://github.com/unxed/f4/issues/1623#issuecomment-5871786656
4. Опции: рекурсия по каталогам, абсолютные пути, фильтр по маске.
5. Кодировка создаваемого файла (комбобокс).
