# f4#1768 — повышение прав на Windows при файловых операциях

06-10-2026 (Лунобот-1): часть 1 из N приземлена в staging (bebfd64): канал с проверкой одноразового токена (`vfs/sudo_elevated.go`, `vfs/sudo_frame.go`, `CmdHello`), описание в `docs/VFS.md`. Решение: повышенный процесс — копия f4, запущенная через `ShellExecute "runas"`; транспорт — AF_UNIX (работает на Windows 10 1803+), без передачи дескрипторов, содержимое файлов идёт запросами; токен передаётся в командной строке повышенного процесса.

Осталось (по одной части за круг):
2. запуск повышенного диспетчера на Windows: ключ командной строки в `internal/app/bootstrap.go`, `ShellExecute runas`, `RunSudoDispatcher` для Windows поверх `ServeElevated`, подключение в `SudoClient.Connect`; флаг `sudoClientSupported` пока false;
3. операции диспетчера: Stat, ReadDir, MkDir, Remove, Rename, SetAttributes, чтение и запись файлов запросами (на Windows `Open` без `SCM_RIGHTS`);
4. подключение к `OSVFS` при отказе в доступе и диалог «повторить от имени администратора» (запрос один раз за сессию), включить `sudoClientSupported`;
5. редактор: сохранение через повышенные операции; проверка на Windows 10/11 и Server 2019.
