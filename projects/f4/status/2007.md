**Приоритет:** 2 (регрессия), **состояние:** `свободен` — продолжается по частям.

## Шаг 1 — сузить область регрессии (16-10-2026, Лунобот-2)
- Тикет сообщает, что `a164575e` (30-09) работает, а `4ad4ae7a` (10-10) ломается с `Cannot paste clipboard image: reading clipboard via /usr/bin/osascript: exit status 1`.
- В затронутом коде `internal/panel/clipboard_image.go:ActionPasteClipboard` вызывает `terminal.ReadClipboardContents`; тот делегирует чтение изображения `goclip.ReadContents`. Текстовый fallback остаётся у `vtui.GetClipboard()`.
- Наиболее сильный первичный кандидат — `9eb3a2ee` (02-10, `feat(panel): paste clipboard images into panel directories`): он добавил чтение изображений через `goclip` и замену `github.com/unxed/goclip v0.1.2` на `github.com/Zoinen/goclip v0.1.3-clipboard.1`. В сравнении endpoints `vtinput` не менялся (1.10 → 1.11 в более позднем bump), но это пока не исключает его влияние.
- Отдельный `331776e8` (08-10) добавил запись изображения в clipboard для Quick View; это не путь чтения при Paste, поэтому не первый кандидат для данного сообщения об ошибке.

## Шаг 2 — причина найдена, исправление (16-10-2026, Лунобот-1)
- Причина (проверена на macOS-раннере, песочница, прогон 38948860019): JXA-скрипт чтения изображения в goclip (`Zoinen/goclip v0.1.3-clipboard.1`, `image_darwin.go`) на буфере без PNG/TIFF вызывает `base64EncodedStringWithOptions` у nil-прокси (`!data` ложно), osascript выходит с кодом 1; `ReadClipboardContents` считал это ошибкой. Текст, файлы и пустой буфер падают одинаково, изображение читается.
- Исправление приземлено в `lunobot/staging` (`cc023b0012ff`, исходный коммит `0cf56f018b61`): `*exec.ExitError` читалки = «нет изображения»; тест на фикстуре и darwin-тест на настоящем буфере (только GitHub Actions; без исправления красный на text/files/empty — прогон https://github.com/unxed/f4/actions/runs/38950140274 ; с исправлением зелёный на macOS вместе с vet и обоими lint — https://github.com/unxed/f4/actions/runs/38950135482 ; ubuntu — https://github.com/unxed/f4/actions/runs/38949268640).
- Тикет `в пути`: после поезда с этим коммитом — «Пробуйте!» по тексту `Проверить:` (разнесёт tick).
- Остаётся вне f4: чинить JXA-скрипт в goclip-форке (проверка типов через `p.types`, а не `!data`), чтобы не опираться на код выхода.
