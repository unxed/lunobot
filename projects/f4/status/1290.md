23-09-2026: PR [#1329](https://github.com/unxed/f4/pull/1329) добавил `StartupWMClass=org.unxed.f4` в поставляемый Linux desktop entry. Это позволяет оконному менеджеру сопоставить GUI-окно f4 с desktop entry и показать иконку приложения в панели задач; терминальный режим по-прежнему не получает GUI-иконку. Сам `.desktop` и hicolor-иконки уже включались в Linux-архивы workflow.

PR #1329, merge-коммит `cf74cc69`, post-merge CI #35912300482 — успех. Локальные сборка и тесты не запускались согласно LUNOBOT.md; проверки выполнены GitHub Actions.
