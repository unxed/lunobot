# Тикет #731

Перенесено из docs/LUNOBOT/731.md рабочего репозитория (29-09-2026); части 1 и 2 приземлены.

После успешной установки обновления f4 теперь предлагает немедленный
перезапуск. При подтверждении новая версия запускается с теми же аргументами
командной строки и рабочим каталогом, после чего старый процесс завершается.
Если запуск не удался, текущий процесс остаётся работать и показывает ошибку.

Откат после неудачного запуска новой версии остаётся частью 2.

Часть 2 сохраняет резервную копию работающего executable перед заменой.
При ошибке установки или запуска новая версия откатывается, а прежняя
отметка установленной версии восстанавливается, чтобы проблемный пакет можно
было предложить снова после исправления.

Проверка выполняется GitHub Actions согласно рабочему процессу Лунобота;
локальные сборки и тесты намеренно не запускаются.
