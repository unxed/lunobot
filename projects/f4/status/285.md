# 285 — кастомная отрисовка элементов интерфейса

Первый срез: общий табличный движок геометрии для графических backend’ов с набором `classic`, без изменения поведения по умолчанию.

План частей:

1. Общая модель фигур и компиляция в пиксельно выровненные прямоугольники; перенести текущий `classic` без визуальной смены.
2. Подключить единый набор к оставшимся графическим backend’ам и добавить проверки эквивалентности.
3. Следующая пользовательская часть — переключаемый набор оформления (начать с `rounded` или токенов контролов после подтверждения владельца).
