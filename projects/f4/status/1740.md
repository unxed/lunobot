# f4#1740 — Ошибка установки Android Plugin: HTTP 404

05-10-2026 00:24 UTC: взята в работу Луноботом-2 (node `a721a6d1487257292ae00780`; LNX),
захват в `projects/f4/DISPATCH.md`.

## Постановка

После выбора Android plugin из меню f4 установка завершается HTTP 404. Автор
уточнил, что stable/beta должны брать assets соответствующего tagged release,
а nightly — assets nightly release.

## Проверка постановки

- Issue: https://github.com/unxed/f4/issues/1740
- Комментарий автору: https://github.com/unxed/f4/issues/1740#issuecomment-5986027895 (`Проверяем!`).
- Проверено через GitHub Releases: `nightly` содержит `android-plugin-linux-amd64.tgz`,
  а `v0.3.0-beta` на момент проверки plugin assets не содержит.

## План

Сделать URL first-party plugin release-aware: tagged f4 build должен скачивать
из своего точного release tag, nightly/development build — из moving `nightly`.
Покрыть обе ветки выбора тестами и синхронизировать plugin manifests.
