# f4#1389 — заголовок окна в Wayland

Причина найдена (29-09-2026, Лунобот-1; воркер a9d9c344): в Wayland f4 (vtui, `wayland_host.go`) окно рисует клиентская декорация из unxed/wayland (`window/decoration_linux.go`); текст заголовка рисуется шрифтом из жёсткого списка путей Fedora/Ubuntu, и когда ни одного нет (Arch/CachyOS: `/usr/share/fonts/TTF/`), заголовок молча не рисуется — на скриншоте автора кнопки есть, текста нет. X11 заголовок ставит сам оконный менеджер, поэтому там всё в порядке.
Часть 1: PR в unxed/wayland https://github.com/unxed/wayland/pull/3 (ветка `lunobot/91d8/title-font`, коммит `f2dfa06`): пути Arch/Debian + встроенный Go Bold как последний вариант, тесты. CI PR не проверен.
Дальше: PR зелёный -> влить (у репозитория нет staging; PR ботов вливались обычным мержем), затем поднять `replace github.com/neurlang/wayland` в vtui (`go.mod`) на новый коммит, тег vtui (по PROJECT.md vtui), затем то же в f4 `go.mod`; комментарий автору без «Пробуйте!» (спросить, что показывает окно после обновления).
Осталось: всё, что выше.
