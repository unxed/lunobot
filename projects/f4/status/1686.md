## Осталось

Общее для частей ниже. Корпус: 49 штатных макросов Far 3 (FarManager/extra/Addons/Macros), статический разбор: 47 используют `Macro{}`, 40 — `Keys`. Реестр функций: `internal/macro/lua_compat.go` (глобалы `panel`, `Panel`, `editor`, `win`, `far`), `lua_api.go`, `lua_mf_extra.go`, `lua_types.go` (интерфейсы хоста `MacroPanelHost`/`MacroEditorHost`/`MacroClipboardHost`, реализация в `internal/app/macro_host.go`). Каждая часть: ветка от свежего staging, тест в `internal/macro` (Lua-фрагмент -> результат), прогон в песочнице (vet + test `internal/macro` и `internal/app`), комментарий в тикет с живым примером макроса.

Функций, которых в main нет (скриптов корпуса -> имя), проверено по исходникам main:
1. Панели: `panel.SetViewMode` (1), `Panel.Select` (1), `APanel.Format`/`APanel.UNCPath`/`APanel.Width` (по 1). Готово: функции есть в `lua_compat.go`/`lua_api.go` и возвращают осмысленное значение (для Width — ширину панели в колонках) либо документированную заглушку; тест в `internal/macro`.
2. Редактор: `Editor.GetStr` (1), `editor.GetStringW` (1), `editor.GetSelection`, `editor.Select`, `editor.SetPosition`, `editor.RealToTab`, `editor.Redraw`, `editor.AddColor`, `editor.DelColor` (по 1; AddColor/DelColor допустимо сделать no-op с логом). Нужно расширить `MacroEditorHost` (`EditorInfo` уже есть, `EditorView.MacroPosition`). Готово: макрос в области Editor читает строку/выделение и двигает курсор, тест с фейковым хостом.
3. `far.*`/`Far.*`: `far.Dialog` (1, самое крупное — отдельно описать план в тикете перед кодом), `far.MkLink` (1), `far.AdvControl`, `far.InputRecordToName`, `far.MacroGetState`, `Far.KeyBar_Show` (по 1), `Menu.GetItemExtendedData`/`SetItemExtendedData`/`HorizontalAlignment`, `Object.CheckHotkey` (по 1; можно заглушкой «нет окна Far»).

5. Остаток `mf.*` вне корпуса (необязательно): `testfolder`, `clip`, `xlat`, `fmatch`, `strpad`; `far.SetConfig`, `far.Clock` (не проверено, есть ли они в main: поиск по `internal/macro` их не нашёл).

Проверка на реальных файлах: статически корпус разобран, а F3.lua, Symlink.lua, UppercaseFolders.lua грузятся целиком (по комментарию в тикете); полный прогон всех 49 файлов через загрузчик не делался — можно добавить тест, который грузит выбранные файлы корпуса и проверяет, что ни один не роняет `Load` (источник файлов — репозиторий FarManager, читать без копирования в f4).
