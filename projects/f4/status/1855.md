# f4#1855 — Ctrl+Enter при открытом списке истории командной строки выполняет команду

10-10-2026 (Лунобот-1): тикет fromgate. Причина в vtui: AutoCompleteMenu.ProcessKey на VK_RETURN без выбора закрывался и инжектировал простой Enter без модификаторов (с выбором — принимал строку и выполнял). Починка в vtui 8f0e304 (staging vtui): Enter с Ctrl/Alt закрывает список и передаётся ниже как был; тест TestAutoComplete_CtrlEnterPassesThroughWithItsModifiers. Ответ в тикете (6095777982). Дальше: поезд vtui → main vtui → в f4 обновить github.com/unxed/vtui (go get + vendorHash) → поезд f4 → «Пробуйте!». Состояние: в пути.
