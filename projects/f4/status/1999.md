# unxed/f4#1999 — Enter на файле в архиве: открыть связанным приложением

**Тикет:** https://github.com/unxed/f4/issues/1999 (ldapomni, enhancement)
**Приоритет:** 3. **Состояние:** `свободен`.

## Разбор (триаж Лунобот-1, 16-10-2026)
- Enter на нерунаемом файле не в `OSVFS` → `internal/app/actions.go` (~2200): «Cannot execute non-runnable files on a remote file system.» Для локальных файлов — `panel.AssociatedFileCommand(path)` + `pf.RunExternalUICommand`.
- Распаковка во временный файл уже есть для F3/F4 (`internal/panel/frame.go` ~6097, `OnClose` удаляет tmp).

## План (ответ автору: https://github.com/unxed/f4/issues/1999#issuecomment-6218560358)
- Для не-OSVFS: скопировать файл во временный каталог (с окном прогресса и отменой, как F3), затем `AssociatedFileCommand(tmpPath)` + `RunExternalUICommand`; сообщение об ошибке оставить только если ассоциации нет.
- Удаление: внешнее приложение возвращает управление сразу (xdg-open/open) — временные файлы удалять при выходе f4 (реестр временных путей), не по возврату команды.
- Изменения в temp-копии обратно в архив не пишутся (для правки — F4).
- Тесты: Enter в ArchiveVFS/mock VFS → файл скопирован в temp, вызвана ассоциация с temp-путём (подмена RunExternalUICommand), путь зарегистрирован на удаление.
