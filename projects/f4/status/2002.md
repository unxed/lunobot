# unxed/f4#2002 — полноценный диалог архивации (Shift+F1)

**Тикет:** https://github.com/unxed/f4/issues/2002 (tarlabnor, «на будущее»)
**Приоритет:** 4. **Состояние:** `свободен`.

## Разбор (триаж Лунобот-1, 16-10-2026)
- Сейчас: `plugins/archive/archive.go` `actionAddArchive` — только `app.InputBox` с именем (`.zip` по умолчанию), формат по расширению; `archive.NewArchiver(fullArcPath, dir, archive.Options{Xattrs: false})`.
- Zipper (`github.com/unxed/zipper/archive`, v0.1.178) `Options` уже умеет: `Solid`/`NonSolid`, `Method` ("zstd","deflate","gzip","store","lzma","bzip2","xz"), `Level` (1–9), `Password`, `EncryptCD`, `SplitSize`, `Tolerant`, `Concurrency`. Форматы: zip (`NewZipArchiver`), tar(+zst/gz/xz/bz2), остальное через fallback (`archives`: .tar.gz, .gz, .zip, .7z с Solid/Password).
- Lite-сборка: `plugins/multiarc` (внешние архиваторы) — отдельный путь, диалог только для обычной сборки, lite — по возможности те же поля через аргументы архиватора (позже).

## План (ответ автору: https://github.com/unxed/f4/issues/2002#issuecomment-6220189814)
1. Окно вместо InputBox: имя, формат (Zip, 7z, tar+gzip/bzip2/xz), уровень, метод, solid (если формат поддерживает); смена формата меняет расширение имени. Отображение на `archive.Options`. Тест: диалог → Options/имя.
2. Шифрование: пароль, «показать пароль», шифрование заголовка (`EncryptCD` для zip; для 7z проверить поддержку header encryption в archives/sevenzip).
3. Разбиение на тома (`SplitSize`).
4. Удалить после архивации, игнорировать ошибки (`Tolerant`), фильтр по маске.
5. Именованные профили (хранить в настройках f4).
6. SFX и строка advanced-параметров — нужна поддержка в Zipper; «файлы, открытые на запись» — Windows VSS, отдельно.
