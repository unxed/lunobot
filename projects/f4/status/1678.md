## Решения по оставшимся частям (Лунобот-1, воркер a94ae638, 29-09-2026 20:20 UTC)

**Индекс точек входа gzip/zstd.** Разобрано: unxed/tar уже даёт индексированный произвольный доступ для локального файла (`NewFS(archivePath, indexPath)`, arcidx/sqlite, dictzip-чанки в gzip, `random_access_proof_test.go`), и f4 им пользуется для локального tar (`plugins/archive/tar_index.go`). Пробел — только цепочка через reader (вложенный слой без локального пути): там `archives.FileSystem` идёт потоком. Настоящий zran-индекс (контрольные точки состояния deflate/zstd-фреймов по ReaderAt родителя) — это новая подсистема в unxed/tar+unxed/archives уровня отдельного проекта и без Windows/CI-фикстур её не проверить на этом шаге; безопасный кусок (без нового формата) уже сделан — `seqMemberReader` убрал квадратичную стоимость при чтении вперёд. Решение: индекс не начинать наугад; следующая часть, если владелец подтвердит масштаб: (1) `unxed/tar`: `NewFSFromReaderAt` с кэшем контрольных точек для gzip (deflate-блоки, окно 32 КБ) и для zstd (границы фреймов), формат кэша — arcidx; (2) `unxed/archives`: использовать его в `FileSystem` для tar.gz/tar.zst при наличии ReaderAt+Size; (3) bump в f4. Захват в unxed/tar (проект `tar`, режим — по `projects/tar/PROJECT.md`: ветка -> PR) ставить только когда часть берётся в работу.

**Observer.** Наблюдение: Observer уже получает вложенность через WASI-ФС поверх `ReadAt` родителя; узкое место — `ExtractItem` пишет элемент целиком в каталог извлечения (temp-файл, ограниченный и удаляется). Выбранный подход для потока элемента без правки ABI модулей: хост подставляет вместо каталога извлечения in-memory/spool-приёмник — модуль пишет через `CreateFile/WriteFile` на пути под `/extract/` (compat `windows.h`), хост-часть `fsbridge.go` отдаёт этот путь как `fs.File`-приёмник, читаемый по мере записи (`io.Pipe` + ограниченный буфер) и потому пригодный как `Open(withStreamRead)` для следующего слоя цепочки. Проверить можно только с CI-сборкой `isoimg.wasm` (`scripts/build_isoimg_test_wasm.sh`), поэтому часть идёт как CI-тест с `t.Skip` без фикстуры, как e2e isoimg. Следующая часть: приёмник в `plugins/observer/fsbridge.go` + тест на stub-модуле (testdata/stub) + e2e цепочка iso > zip.
