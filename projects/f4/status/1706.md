# f4#1706 — длинные имена шрифтов вылезают за выпадающий список (Windows)

Причина: `VMenu.DisplayObject` (vtui) рисовал текст пункта без обрезки по ширине окна; `ComboBox.Open` ограничивает ширину краем экрана. Исправление (vtui, коммит `3e17e6d5` в `lunobot/staging` vtui, тест `vmenu_overflow_test.go`): текст обрезается по ширине с «…». Комментарий в тикете отправлен без «Пробуйте!».
Осталось: (1) поезд vtui → main (`tick vtui`), (2) релиз: следующий `vX.Y.Z` тегом на коммите мержа (`gh api repos/unxed/vtui/tags --jq '.[0].name'`), (3) bump `go.mod` f4 (`go get github.com/unxed/vtui@vX.Y.Z` через песочницу, `go.sum` по её diff; vendorHash ведёт бот), land, (4) «Пробуйте!» после влития поезда f4 с новым vtui, TRIAGE `проверяют`. Захват «f4#1706» в DISPATCH.md держится до bump.
