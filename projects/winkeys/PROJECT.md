# winkeys

- Код: https://github.com/unxed/winkeys (свой репозиторий владельца, не форк): константы клавиш Win32 и общая структура `InputEvent`.
- Задачи: тикеты и PR этого репозитория, плюс правки, которые нужны unxed/vtinput, unxed/vtui и unxed/f4.
- Режим публикации: PR
- Отладка GitHub CI: нет (маленький пакет без зависимостей, тесты быстрые)
- CI: `coverage.yml` (`go test ./...`, ubuntu) на push в main и на PR — это и есть обязательная проверка; матрицы ОС нет.
- Зависимости: нет. От winkeys зависят unxed/vtinput, unxed/vtui, unxed/f4: правка `InputEvent`, ломающая API, требует парных правок там.
- Релизы: ручной тег; схема: vX.Y.Z (последний v0.1.1 на 21-10-2026). После мержа, нужного потребителям, — следующий тег, иначе они берут pseudo-version.
- Язык общения: по языку автора (PR uranic2 — английский).
- Паспорт заведён 21-10-2026 по § 2 («Репозитории-зависимости владельца»); строки в `INDEX.md` нет, её согласуют с владельцем.
